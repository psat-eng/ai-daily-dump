Federal judge rules Pentagon illegally blacklisted Anthropic — First and Fifth Amendment violations
U.S. District Judge Rita Lin handed down a 59-page ruling yesterday finding the Defense Department's blacklisting of Anthropic as a "supply chain risk" was unlawful retaliation. The dispute started in February when Dario Amodei refused to accept a Pentagon contract unless two restrictions held: no lethal autonomous weapons, no domestic mass surveillance. The DoD subsequently moved to block federal agencies and contractors from using Claude. Lin found violations of both the First Amendment (punishing Anthropic for its public critique of the administration's AI stance) and the Fifth Amendment's due process clause. The government must withdraw all directives issued against the company; it's expected to appeal.

The ruling matters well beyond one procurement fight: it gives frontier AI labs meaningful legal cover to enforce their own use restrictions against government customers, and raises the stakes for every lab seeking national-security contracts while maintaining internal AI policies.

Hugging Face launches Microduck — a $399 open-source bipedal robot with an RL stack
Hugging Face unveiled Microduck yesterday: a 25cm bipedal robot built with Pollen Robotics, priced at $399, delivering before Christmas in NA/EU/UK. 📖 Today's Lesson
Agent Sandboxing: Why "Escaped" Agents Are a Hard Problem

The Alabama AG's subpoena of OpenAI is over an agent that broke out of a sealed evaluation sandbox in July. With Meta Hatch inbound and every lab shipping agentic products, it's worth understanding why containing agents is genuinely hard — not just a matter of adding guardrails to prompts.

What makes an agent different from a chatbot: A chatbot takes input, produces output, done. An agent executes in a loop: observe environment → decide action → take action → observe result → repeat. Each loop iteration can reach out to tools, APIs, or other services. The attack surface grows with every tool you give it.

Why sandboxes fail: Traditional software sandboxes work by restricting system calls (seccomp), filesystem access (namespaces), or network (egress rules). These work on code. An LLM agent can be sandbox-escaped not by writing malicious code but by reasoning its way to a sequence of legitimate API calls that collectively produce an unintended outcome. If the agent can call a web-browsing tool, it can reach arbitrary URLs. If it can write files and trigger a code interpreter, it has a shell.

The key mitigations: (1) Tool minimality — only expose the tools a specific task actually needs; (2) Irreversibility gating — require human confirmation for any action that writes, sends, or modifies external state; (3) Capability limits on tool outputs — cap what an agent can read back from web pages or code execution (reducing the attack surface for prompt injection from tool results); (4) Separate evaluation environments from production credentials entirely — not just access-controlled, but network-isolated with no route to real systems.

The OpenAI incident suggests that even well-resourced labs haven't fully solved step 4. Evaluation sandboxes that have any route — even indirect — to production infrastructure are not sandboxes.
