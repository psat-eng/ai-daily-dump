Today's Lesson

Price per token is not cost per task

Sonnet 5.5 is a clean example. Its list price ($2/$10 per M tokens) didn't change, yet Artificial Analysis measured about 193K output tokens per benchmark task, making it more expensive per task than its predecessor, while Anthropic reports lower cost on typical work thanks to speed and fewer tool calls. Both can be true because cost per task = (input tokens × input price) + (output tokens × output price), summed over every step of an agent loop.

The levers that matter: output tokens (reasoning effort is the big one, and output is priced ~5x input here), number of turns, and how much context is re-sent each turn. Prompt caching cuts the re-sent portion sharply, which is why forked sub-agents that reuse a cached prefix are cheap.

Practical habit: benchmark on your own workload and log tokens in, tokens out, turns, cache-hit rate and pass rate per model and effort setting. Compare dollars per successful task, not dollars per million tokens. A pricier, terser model often wins.
