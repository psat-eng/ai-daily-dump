JIT-Agent: A Model That Writes Its Own Agent Harness
NUS · Hugging Face Papers · Aug 26, 2026 paper
JIT-Agent from NUS trains a model to synthesize an adaptive agent harness for any off-the-shelf LLM on the fly — tools, scaffolding, retry logic, all generated at task time. 🚀 New Releases & Updates
GLM-5.3-Flash (Ox Alpha) — Z.AI's 320B MoE Goes MIT
Z.AI · Aug 26, 2026 MIT MoE
GLM-5.3-Flash is Z.AI's "Ox Alpha" release: 320B total parameters, 18B active, native multimodal, 1M-token context. The architecture combines sparse and linear attention for the first time in the GLM series — sparse layers handle precise retrieval, linear attention handles the long tail of context at much lower cost. Z.AI claims it beats GLM-5.2 across their evals at 1/10th the serving cost. Available through their API and as open weights under MIT. Worth watching for 1M-context production workloads where cost matters.

📖 Today's Lesson
Hybrid Attention: Why Mixing Sparse and Linear Attention Cuts Long-Context Costs Dramatically

Standard transformer attention is O(n²) — every token attends to every other token. At 128K tokens that's roughly 16 billion attention score computations per layer, which is why long-context serving is expensive even on fast hardware.

Two approximate alternatives emerged: sparse attention (each token attends to only a subset of positions — nearby tokens, a few global "sink" tokens, and some random long-range ones) and linear attention (rewrites the attention operation to accumulate a running state vector instead of materializing the full N×N matrix, giving O(n) complexity). Both cut costs, but each has a weakness: sparse attention still misses some long-range dependencies, and linear attention degrades on tasks that need sharp, precise retrieval from specific positions in a long context.

The insight behind hybrid attention (as in GLM-5.3-Flash and several recent architectures) is that you don't need every layer to do the same thing. Stack them: a few full-attention or sparse-attention layers handle precise recall — "what was the exact value at position 47,000?" — while the majority of layers use linear attention to cheaply process and summarize the long tail of context. In practice, 20–30% full-attention layers plus 70–80% linear-attention layers gives most of the retrieval accuracy of pure full attention at a fraction of the KV cache footprint and compute cost.

For inference engineers, the practical upshot: hybrid models need differently sized KV caches per layer type, and serving frameworks need to handle mixed layer schedules. vLLM's Model Runner V2 and SGLang's scheduler both have partial support for this already — expect it to become table stakes as more hybrid-architecture models ship.
