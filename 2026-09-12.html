Agnes-3.0-Flash 33B — hybrid delta-rule + attention, 262k context, multimodal
Agnes-AI on Hugging Face · 188 upvotes on r/LocalLLaMA · today
Interesting architecture drop today: Agnes-3.0-Flash is a 33B multimodal (text/image/video) model where 54 of 72 decoder layers are gated delta-rule recurrent layers, with global attention appearing only every 4th layer (18 layers total). The practical upshot: only those 18 attention layers hold a growing KV cache — the recurrent layers have fixed-size state regardless of sequence length. This is how you get to 262k context without your KV cache going out of control. Architecture specs: 24 query heads / 4 KV heads (6:1 GQA) on attention layers; 16 key / 48 value heads on delta-rule layers with causal conv in front. Tool calling, adjustable reasoning effort, 3-axis rotary positions for text/image/video. Worth watching — hybrid linear-recurrent architectures have been talked about theoretically for a while, and this is a real weights drop.

📖 Today's Lesson
Per-Tensor Quantization in GGUF: Why One Q4 Doesn't Fit All Layers
When you run a GGUF model with llama.cpp, every parameter gets stored in a compressed format like Q4_K_M or Q8_0. The naive approach — and what most early GGUFs did — is to apply one quantization scheme uniformly across the entire model. The problem: different weight matrices have wildly different sensitivity to precision loss.

Embedding tables and output projections sit at the boundaries where token IDs are mapped to and from the high-dimensional representation space. Small errors here propagate through the entire forward pass and degrade output quality noticeably. Attention query/key projections in the first and last few layers are similarly sensitive. By contrast, mid-network feed-forward weights in middle layers tend to be much more robust — you can drop them to Q3 or even Q2 without obvious degradation.

Per-tensor layout maps exploit this: instead of blanket Q4_K_M, you assign a specific quantization type to each named tensor based on empirical sensitivity. The embeddings might stay at Q8 or even F16. The bulk of the FFN weights drop to Q4_K_S or Q3_K_M. A few critical attention projections hold at Q6_K. The result is roughly the same file size as a uniform Q4_K_M but measurably better perplexity.

bartowski's work on Qwen3.8-27B is the first widely deployed example, with an accompanying blog post showing before/after quality metrics per tensor group. Expect this to become the standard approach for serious GGUF releases — the imatrix method (importance matrix-guided quantization) laid the conceptual groundwork, and per-tensor layout maps are the logical next step: not just "how much" to quantize, but "what scheme fits each tensor's role."
